# Феодальная раздробленность Руси

Учебный сайт по истории России на тему «Феодальная раздробленность на Руси (XII–XV века)».

## Разделы

| Страница | Что внутри |
|---|---|
| `index.html` — Главная | Распадающаяся карта Руси, определение, «дробление» в цифрах, ключевые даты, словарь терминов с поиском |
| `prichiny.html` — Причины | Предыстория, интерактивная схема «лествичного права», Любечский съезд, четыре группы причин, мнения историков, вопросы |
| `hod.html` — Ход событий | Четыре этапа и интерактивная хронологическая лента 1054–1521 гг. с фильтрами и летописными датами |
| `knyazhestva.html` — Княжества | Интерактивная карта 1237 г., вкладки о Владимиро-Суздальском, Новгородском и Галицко-Волынском центрах, схемы власти, сравнительная таблица |
| `knyazya.html` — Князья | Галерея портретов с биографиями, родословная схема Рюриковичей |
| `dokumenty.html` — Документы | 10 источников: подлинник и перевод, пояснение, вопросы с ответами |
| `posledstviya.html` — Последствия | Плюсы и минусы, расцвет культуры, нашествие, объединение вокруг Москвы, вывод |
| `test.html` — Тест | 15 вопросов (выбор ответа, карта, портрет, хронология) с оценкой и разбором |
| `istochniki.html` — Источники | Литература, издания источников, электронные ресурсы, авторы и лицензии иллюстраций |

## Как открыть

Сайт статический — сборка не нужна. Достаточно открыть `index.html` в браузере.

Чтобы опубликовать через GitHub Pages: **Settings → Pages → Deploy from a branch**, выбрать ветку и папку `/ (root)`.

## Устройство

- `assets/css/style.css` — оформление (светлая и тёмная темы, адаптивная вёрстка).
- `assets/js/` — интерактив: `map.js` (карты), `timeline.js` (лента), `ladder.js` (лествица), `princes.js` (галерея), `quiz.js` (тест), `glossary.js` (словарь), `main.js` (меню, тема, подсказки, лайтбокс).
- `assets/js/map-data.js` — геометрия карты, перерисованной по «Kievan Rus in 1237 (ru).svg» (Hellerick, CC BY-SA 3.0).
- `assets/img/` — иллюстрации с Wikimedia Commons (авторы и лицензии — на странице «Источники»).
- `assets/fonts/` — шрифты Ponomar, Literata, Onest (SIL Open Font License).
